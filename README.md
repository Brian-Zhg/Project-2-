# Project-2-NY SAFE
NY SAFE

NYC Restaurant Inspection Map

About: 

NY SAFE is an interactive web application that allows users to explore New York City's restaurant inspection data through an interactive map and data visualizations.

Features:

- Interactive map displaying restaurant locations.

- Color-coded markers representing inspection grades.

- Restaurant inspection history and violation details.

- Heatmap displaying the concentration of restaurant violations.

- Search and filter restaurants by name and inspection grade.

- Statistics dashboard with cuisine filtering.

- Toggle controls to show or hide the heatmap.
